# J-Runner Practice

A look-alike of J-Runner with Extras for practicing Xbox 360 RGH on a virtual console.
It never touches real hardware, and every dump, image and CPU key it makes is fake.

**Made by nobehong**

## Download

Grab `J-Runner Practice.exe` from the releases page and run it. That single file is the
whole app - no install, no extra files. It creates anything else it needs on first run.

## Updating

The app checks this repository on start and offers any newer version, then swaps itself
and relaunches. You can also use Check for Updates in the menu, or turn the check off in
Settings.
